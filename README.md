# Vector3.Time
 Расширние для структуры Vector3 для Unity


По многочисленным просьбам создано решение, которое позволяет легко вычислить время, необходимое для преодоления заданного расстояния с заданной скоростью. Этот утилитный класс предоставляет метод-расширение для `Vector3`, который вычисляет время, необходимое для путешествия на определенное расстояние с заданной скоростью.

![ASD](readme/asd.jpg)


## Возможности

- **Вычисление времени путешествия**: Рассчитывает время, необходимое для преодоления расстояния, представленного `Vector3`, с заданной скоростью.
- **Обработка крайних случаев**: Если скорость меньше или равна нулю, метод возвращает `float.PositiveInfinity` и выводит предупреждение в консоль.

## Установка

1. Добавьте файл `VectorToTimeExtension.cs` в ваш проект.
2. Убедитесь, что он находится в папке `_Project/Code/Utils`, или адаптируйте пространство имен под структуру вашего проекта.

## Использование

Для использования метода расширения просто вызовите его для любого объекта `Vector3`, передав аргументом скорость путешествия. Метод вернёт время, необходимое для преодоления этого расстояния.

### Пример:

```cs
using _Project.Code.Utils;
using UnityEngine;

public class TravelTimeExample : MonoBehaviour
{
    [SerializeField] private Vector3 destination = new Vector3(10f, 0f, 0f);
    [SerializeField] private float speed = 5f;

    private void Start()
    {
        float timeRequired = destination.Time(speed); 
        //также можно transform.position
        Debug.Log($"Время: {timeRequired} секунд.");
    }
}
```
